# Bole Weather Icon Set

Individual SVG icons for the Bole Weather front-end project.

## Folders
All SVGs are intentionally kept in one folder for easy first-project use.

## Usage
HTML:
<img src="icons/search.svg" alt="Search">

CSS:
You can use the SVG as an image, or inline the SVG when you want to control `currentColor` directly.

The SVGs use `currentColor`, so inline SVGs inherit the text/icon color from CSS.

## Icon groups
UI: home, heart, map, bell, settings, search, menu, sun, plus, pencil, x,
chevron-left, chevron-right, refresh, star, map-pin, navigation, locate.

Weather/details: temperature, humidity, wind, pressure, visibility, rain,
partly-cloudy, cloudy, sunny, thunderstorm, fog, clear-night, cloudy-night,
sunrise, sunset, air-quality, umbrella, check, info, alert-triangle.
